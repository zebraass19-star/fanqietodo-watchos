# 设计规范（Design Spec）

> 版本 v1.0 · 视觉实现的唯一标准。整体参考苹果第一方 App（计时器/体能训练）的克制、大字号、高对比风格。

## 1. 设计原则

1. 一屏一件事：手表屏幕小，每个页面只突出一个核心信息
2. 黑底 + 单一强调色：信息层级靠字号与透明度区分，不用多种颜色
3. 触达即达：按钮足够大（≥ 44pt），状态变化有触感/动效反馈
4. 圆环随剩余时间平滑收窄，大数字一秒一跳不抖动

## 2. 色彩（唯一色板）

| Token | 值 | 用途 |
|---|---|---|
| 主色 UltraOrange | `#FF6000`（RGB 255, 96, 0） | 强调：主按钮、圆环、今日柱、专注阶段标签 |
| 背景 | 纯黑 `#000000` | 所有页面背景 |
| 文本主色 | 白色 | 大数字、标题 |
| 文本次级 | 白 50% 透明度 | 副信息 |
| 文本三级 | 白 35% 透明度 | 提示性小字 |
| 圆环轨道 | 白 12% 透明度 | 进度环底色 |
| 往日柱 | 主色 40% 透明度 | 图表非今日柱 |
| 次要按钮底 | 白 15% 透明度 | 取消等次要圆形按钮 |

- AccentColor = #FF6000（系统控件着色）
- 全局强制深色模式（`.preferredColorScheme(.dark)`）

## 3. 字体排版

- 倒计时大数字：system 48pt semibold + `monospacedDigit()` + `contentTransition(.numericText)`
- 阶段标签：16pt semibold（专注 = 主色，休息 = 白色，暂停/待机 = 三级灰）
- 页面标题：17pt semibold；「今日分钟数」28pt semibold；图表轴标签 10pt
- 待机页副标题（时长回显）：13pt 三级灰

## 4. 页面规格

### 4.1 主框架（ContentView）

- 横向分页 TabView（`.tabViewStyle(.page)`），共 2 页，底部圆点指示，背景纯黑
- 右上角齿轮按钮 → 弹层（sheet）打开设置页；设置页带「完成」按钮

### 4.2 第一页 · 计时器（TimerView）

- 纵向布局：阶段标签 → 圆环（内嵌剩余时间）→ 控制按钮
- 圆环：直径 150pt、线宽 10pt、圆头端点；`trim` 从满环随进度收窄（苹果计时器式）；暂停时整体 40% 透明度；完成态为满环
- 各状态按钮：
  - 待机（idle）：副标题「专注 25 分钟 · 休息 5 分钟」+ 56pt 橙色圆形「开始」
  - 计时中（focus/rest）：44pt 灰底 ✕（取消）+ 52pt 橙底 ⏸（暂停）
  - 已暂停：灰底 ✕（取消）+ 橙底 ▶（继续），标签「已暂停」
  - 完成待确认（focusDone）：橙色胶囊「开始休息」+ 灰色胶囊「跳过休息」
  - 完成待确认（restDone）：橙色胶囊「开始专注」+ 灰色胶囊「结束」

### 4.3 第二页 · 统计（StatsView）

- 顶部：标题「专注统计」→「今日 45 分钟」（28pt 白色 semibold）→「近 7 天共 120 分钟」（13pt 三级灰）
- 柱状图（Swift Charts）：单一橙色系——今日柱 100% 亮橙、往日柱 40% 透明橙；柱宽约 10pt、圆角 3；底部一条基准线（白 15%）
- 隐藏 Y 轴；X 轴中文单字标签（今/一/二/三/四/五/六/日），「今」用主色加粗
- 0 分钟的日子：留空位不画柱（基准线保持存在，诚实呈现无数据日）
- 颜色纪律：数值文字一律用白色/灰色，橙色只用于图形标记

### 4.4 设置页（SettingsView，弹层）

- Form 两节：专注时长 Picker（15/20/25/30/45/60 分钟）、休息时长 Picker（5/10/15/20 分钟）
- 页脚说明：「修改将在下一轮开始时生效。」
- 维护行：「清除统计数据」（弹确认后清空）
- DEBUG 构建额外提供「1 分钟」档位（快速测试用）

## 5. 动效与反馈

- 圆环每秒线性过渡（`.animation(.linear(duration: 1), value: progress)`）
- 触感反馈：阶段完成 `.success`、开始/继续 `.start`、取消/暂停 `.stop`
- 系统通知自带声音 + 触感（使用默认）

## 6. 图标

- 黑底 + 居中橙色圆环（呼应计时圆环），由脚本 tools/make_icons.py 生成各尺寸 PNG
- 占位方案：脚本生成纯几何图形，后续可替换为手绘图标
