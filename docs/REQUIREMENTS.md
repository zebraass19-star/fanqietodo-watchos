# 需求规格说明书（Requirements）

> 版本 v1.0 · 2026-08-27 确认 · 本文档是产品需求的唯一标准，功能以本文为准。
> 修改需求必须先更新本文档，并在当日开发日志中记录变更。

## 1. 产品概述

番茄钟：运行于 Apple Watch 的独立手表应用（watchOS ≥ 11.0），帮助用户以「专注 25 分钟 / 休息 5 分钟」循环工作，并记录每日专注时长。界面中文，应用显示名「番茄钟」。

## 2. 目标用户与场景

- 用户：追求专注效率的 Apple Watch 用户（当前为开发者本人）
- 核心场景：开始专注 → 计时结束收到系统通知 → 点通知按钮进入休息 → 休息结束收到通知 → 点按钮开始下一轮专注

## 3. 功能需求

| 编号 | 功能 | 详细说明 | 优先级 |
|---|---|---|---|
| F1 | 专注计时 | 默认 25 分钟，设置页可选 15/20/25/30/45/60 分钟 | P0 |
| F2 | 休息计时 | 默认 5 分钟，设置页可选 5/10/15/20 分钟 | P0 |
| F3 | 专注结束通知 | 系统本地通知「专注完成」，带「开始休息」「跳过休息」两个按钮 | P0 |
| F4 | 休息结束通知 | 系统本地通知「休息结束」，带「开始专注」按钮 | P0 |
| F5 | 按钮续接 | 点通知按钮即开始下一阶段（App 在后台被系统唤醒处理） | P0 |
| F6 | 暂停/继续 | 计时中可暂停，暂停期间倒计时冻结，可继续 | P1 |
| F7 | 取消 | 可放弃当前阶段；已完整完成的专注仍计统计，未完成不计 | P1 |
| F8 | 每日统计 | 按天累计「完整完成」的专注分钟数 | P0 |
| F9 | 近 7 天图表 | 第二页柱状图展示近 7 天（含今天）的专注分钟数 | P0 |
| F10 | 分页主界面 | 左右滑动切换两页，底部圆点指示 | P0 |
| F11 | 设置 | 右上角齿轮 → 专注/休息时长分别设置；另含「清除统计数据」 | P0 |
| F12 | 首次权限 | 首次启动请求通知权限；被拒绝时待机页显示一行提示 | P0 |

## 4. 已确认的产品决策

1. 「跳过休息」= 直接开始下一轮专注（不回到待机）。
2. 统计口径：只统计完整完成的专注；取消/中途放弃不计；跨午夜的专注计入「结束当天」。
3. 循环为手动续接：不点通知按钮则不自动开始下一阶段；漏点通知时，下次打开 App 会自动补记统计并显示「专注完成」界面（与通知按钮一致的选项）。
4. 界面文案中文；应用显示名「番茄钟」。
5. 休息倒计时圆环与专注同为 Ultra 橙色（保持统一主题）。

## 5. 非功能需求

- 系统：watchOS 11.0 起；用 Xcode 26（watchOS 26 SDK）构建
- 视觉：黑色背景 + Apple Watch Ultra 橙 (#FF6000) 主色，参考苹果第一方 App 风格（详见 docs/DESIGN.md）
- 可靠性：倒计时与通知不依赖 App 保持运行——手表熄屏、重启、杀掉 App 后仍能正确计时/提醒（详见 docs/TECH.md）
- 数据：仅存本机 UserDefaults，不上传云端
- 性能：仅秒级刷新，不常驻后台任务，不消耗额外电量

## 6. 明确不做（v1）

- 不做自动循环（无需点击、自动开始下一阶段）
- 不做 iCloud 同步、账号体系、App Store 专属功能
- 不做多语言（v1 仅中文）
- 不做手表表盘复杂功能（complication，后续版本考虑）
