# 番茄钟（watchOS）

一个运行在 Apple Watch 上的独立番茄钟 App：专注 25 分钟 ↔ 休息 5 分钟循环，阶段结束发系统通知（带「开始休息 / 开始专注」按钮，点一下直接进入下一阶段），并自动记录每日专注时长，主界面第二页有近 7 天柱状图。

- 中文界面 · 黑色背景 + Apple Watch Ultra 橙（#FF6000）
- 仅手表应用（无需 iPhone 伴侣 App），watchOS 11.0 起，Xcode 26 构建
- 熄屏、杀 App、重启手表都不影响计时（倒计时由系统通知 + 持久化状态驱动）

## 怎么装到手表（需要一台 Mac）

> 代码在 Windows 上也能继续写（推送后云编译自动验证），但**最终安装必须用 Mac**。

### 准备工作

1. **一台 Mac**：二手 Mac mini 约 ¥2000–3000 即可；或借用朋友的。
2. **Apple ID**：免费的个人账号就够，不需要 ¥688/年的开发者账号。
3. **Apple Watch**：Ultra / Ultra 2 / Series 10 级别，系统 watchOS 11 以上。
4. **iPhone**（手表本来就连着）：装 App 时手机要在旁边，走 iPhone 中转。

### 安装步骤

1. Mac 上打开 App Store，搜索安装 **Xcode**（免费，很大，耐心等）。
2. 打开 Xcode → 菜单栏 `Settings → Accounts` → 左下角 `+` → 登录你的 Apple ID。
3. 打开本项目：双击 `PomodoroWatch.xcodeproj`。
4. 左侧选中工程名 `PomodoroWatch` → 右侧 `Signing & Capabilities` 标签页 → 勾选 `Automatically manage signing` → `Team` 选你刚登录的 Apple ID（个人团队）。
5. 如果系统提示 Bundle Identifier 重复，把 `com.example.pomodoro-watch` 改个自己独有的名字，比如 `com.你的名字.pomodoro`。
6. **手表开启开发者模式**：手表上进入 `设置 → 隐私与安全性 → 开发者模式`，打开开关后按提示**重启手表**。
   （iPhone 上也要开：`设置 → 隐私与安全性 → 开发者模式`。）
7. 手表戴在手上并解锁；Xcode 顶部设备栏选「你的 Apple Watch」→ 点 ▶ 运行。第一次安装会弹密码确认，输入手机/手表密码即可。

### 重要：免费账号 7 天过期

免费 Apple ID 装的 App **7 天后会打不开**，解决办法：手表 App 打不开时，重新连 Mac 按上面第 7 步再装一次即可（2 分钟的事，数据不会丢）。

### 装好后怎么快速测试

1. 打开 App，点右上角齿轮（调试版），把专注和休息时长都选 **1 分钟**（只调试版有）。
2. 点「开始」→ 1 分钟后手表弹出「专注完成」通知 → 点「开始休息」→ 1 分钟后弹出「休息结束」→ 点「开始专注」。
3. 全程不用盯着屏幕，熄屏也行 —— 这就是正式版的完整使用方式。

## 日常怎么改代码（没有 Mac 也能改）

1. 改 `PomodoroWatch/` 下的源码（改需求先看 `docs/REQUIREMENTS.md`，改界面先看 `docs/DESIGN.md`）。
2. 推送：`git push`。
3. 打开 GitHub 仓库的 `Actions` 页：编译通过 = 绿勾；失败 = 红叉，**点开失败的那次运行，错误原因已经变成了代码旁的注释**，直接看就知道哪行错了。
4. 通过后再改下一步。全部改完，拿 Mac 装一次即可。

## 常见问题

- **收不到通知？** 检查：手表 `设置 → 通知 → 番茄钟` 是否开了「允许通知」；App 待机页若显示「通知已关闭」提示行，去系统设置把通知打开再回 App。
- **统计数字和实际不符？** 只统计**完整完成**的专注；中途取消/放弃的不计。跨午夜的专注记在结束那天。
- **改了时长没生效？** 设置里的修改从**下一轮**开始生效，进行中的本轮不变。
- **图标/显示名怎么改？** 图标重跑 `tools/make_icons.py`（或直接替换 `Assets.xcassets` 里的 PNG）；显示名改 `Info.plist` 的 `CFBundleDisplayName`。
